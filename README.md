# gate — приватный роутер на Raspberry Pi

Wi-Fi точка доступа на Raspberry Pi, которая прозрачно заворачивает весь трафик подключённых
устройств и собственный трафик малины в многохоповую зашифрованную цепочку серверов. Устройствам
ничего ставить не нужно: подключился к Wi-Fi — и трафик уже идёт через цепочку.

```
устройства ─Wi-Fi─> малина ──Reality──> C1 ──Reality──> C2 ──> интернет
                  (AP, TPROXY)        (реле)          (выход: прямой / OpenVPN / SOCKS5 / PPTP)
```

Транспорт — xray-core, VLESS + **REALITY**: настоящий TLS 1.3 с маскировкой под обычное
соединение к реальному сайту, `flow=xtls-rprx-vision`, отпечаток Chrome. Каждое плечо —
отдельный Reality-туннель (от хопа к хопу): реле C1 снимает свой слой и заново шифрует к C2.
Поэтому C1 знает IP малины, но наружу не выходит; C2 выходит в интернет, но IP малины не видит.
Адреса назначения видны обоим звеньям, содержимое HTTPS — никому из них.

## Возможности

- **Полосы — свой выход каждому устройству.** Ноут ходит прямым C2, телефон — через OpenVPN,
  ещё одно устройство — через SOCKS5-прокси; одновременно и независимо. Устройство привязывается
  по MAC, адрес закрепляется в DHCP.
- **Fail-closed везде.** Если назначенный выход лёг — трафик устройства блокируется, а не
  уходит мимо. Killswitch на выходном хопе: без живого туннеля маршрут — в blackhole.
- **Защита от DNS-утечек.** Свой резолвер у каждой полосы: шифрованный DNSCrypt для прямого
  выхода, резолверы, пушнутые VPN-туннелем, — для VPN-полосы. Собственный DNS малины тоже идёт
  своей полосой. `gate dns` проверяет, какой резолвер видит мир.
- **Внешние выходы на C2:** OpenVPN (чужие `.ovpn`, включая Windows-ориентированные — нормализуются
  автоматически), SOCKS5 с автоопределением возможностей (TCP / remote-DNS / UDP), PPTP.
- **Подмена TCP/IP-отпечатка ОС** на выходе (NFQUEUE + Scapy) — для VPN-выходов.
- **CLI `gate`** — весь жизненный цикл: развёртывание цепочки, выходы, полосы, диагностика
  с автопочинкой (`gate doctor`), логи, Wi-Fi/WAN, MAC-адреса.
- **Веб-панель** на чистом Python без зависимостей: только из локальной сети, пароль, анти-CSRF,
  строгий allowlist команд. Полосы, подписи устройств, загрузка `.ovpn`-конфигов файлом.
- **Развёртывание под ключ.** Визард поднимает чистый VPS в звено цепочки: ключи, конфиги,
  фаервол (SSH каждого хопа заперт на предыдущий узел). Офлайн-установка xray из пиннованного
  бинаря — для серверов, где GitHub недоступен.
- **Самовосстановление.** После простоя без RTC часы малины выставляются по цепочке; маршрут
  VPN переживает внутренние реконнекты OpenVPN; `gate doctor` чинит tproxy, службы, DNS.

## Требования

- Raspberry Pi 5 с Raspberry Pi OS Lite 64-bit; Wi-Fi для точки доступа — встроенный или
  USB-адаптер, WAN — Ethernet или второй Wi-Fi.
- Два VPS (реле и выход): Ubuntu 22.04/24.04 или Debian 11/12, amd64, root-доступ, виртуализация
  с `/dev/net/tun` (KVM и т.п., не OpenVZ/LXC — иначе OpenVPN-выход не поднимется).

## Установка

Сборка раздачи (на машине разработчика):

```bash
bash provision/make-gate-dist.sh        # → dist/gate-<версия>.tar.gz
```

На малине:

```bash
tar xzf gate-<версия>.tar.gz && cd gate-<версия> && sudo ./install.sh
sudo reboot
gate setup                    # визард: цепочка C1 → C2, свои ключи
gate web passwd && gate web on
```

Обновление: новый архив → `sudo ./install.sh --update` (конфиги и ключи сохраняются).
Подробно про цепочку, модель ключей и формат `chain.json` — [provision/README.md](provision/README.md).

## Основные команды

| | |
|---|---|
| `gate info` | статус роутера |
| `gate doctor` | проверка и починка (после обновления, ребута) |
| `gate client list` | кто на каком выходе |
| `gate client <ip\|mac\|подпись> exit c2\|vpn\|socks:<профиль>\|auto` | персональный выход |
| `gate global {ovpn\|pptp\|socks [профиль]} on` · `gate global off` | выход по умолчанию |
| `gate ovpn set <файл.ovpn> [логин] [пароль]` | OpenVPN-конфиг на выход |
| `gate profile {list\|save\|use\|rm}` | сохранённые носки / VPN-конфиги |
| `gate dns` | проверка DNS-утечки |
| `gate clock` | часы малины (нет RTC) |
| `gate help` | всё остальное |

Все команды дополняются по Tab.

## Секреты

В репозитории нет ключей и адресов реальной цепочки. `chain.json` (приватные ключи Reality,
UUID) живёт только на малине в `/etc/gate/` с правами 600; в репо — пример
`provision/chain.example.json`. Снапшоты и прочие секреты разработчика хранятся вне дерева
проекта, `.gitignore` — второй рубеж.
